File Role Words
firmware/j1850.pe Hart 0 is a VPW transmitter node: frames from the host with the CRC added, IFS before SOF, every symbol (64, 128, 200 us) exact to the clock, bitwise arbitration, EOD, and an in-frame response read when the header asks for one. Hart 1 is a VPW receiver node: times every symbol, rebuilds the bytes, checks the CRC at EOD, reports the frame, and answers frames addressed to it with an in-frame response (normalization bit and its address). The two pins sit on the one bus wire. 307 of 512 (hart 0 158, hart 1 149)

No RTL change: existing instructions only (twait grid of 8 us, high/rel, shin, waitp.to.frz with tgeth to time symbols, the CRC unit as CRC-8, ld/st, host FIFO). Checked in simulation only, not on a board.

Pins

Pin Use
P0 transmitter: drives the bus high (active) or lets it go
P1 receiver: the same, for its IFR

The bus idles low (passive) through a pull-down; on a vehicle each pin goes through a VPW transceiver. Neither pin is ever driven low, so both can sit on one wire.

Timing

Transmitter: one period of the twait grid is 8 us (200 ticks). A symbol lasts 8, 16 or 25 periods; every level change comes three ticks after a grid boundary, so every symbol is exact to the clock (64.00, 128.00, 200.00 us measured before the pad rule). Since branch int3 (revisions) a push-pull high from release is enabled one clock after the instruction (dual_role.md); this bus idles low, so the line shows it: every active symbol is one clock (20 ns) shorter, 63.98, 127.98 and 199.98 us, and the passive one before it one clock longer, 64.02 and 128.02 us, all inside the Table 5 transmit limits (49 to 79, 112 to 145, 182 to 218 us). Before SOF the bus must have been passive for 300 us (7,500 ticks, counted again after every activity). Arbitration: one period into every passive symbol the bus must be passive (else another node holds an active long 0 against its active short 1), and nine periods into a passive long 1 as well (else another node's passive short 0 has ended); on a loss it lets go, reports the byte it lost in and does not retry. After the last byte it keeps the bus passive for EOD (25 periods); with K = 0 it waits up to 80 us more for the normalization bit, then reads one byte.

Receiver: each symbol is timed with waitp.to.frz from a 4,500-tick (180 us) count; the timer high byte (256-tick steps) gives: under 36.6 us noise, up to 98.1 us short, up to 169.8 us long, 180 us or more SOF (when active and ending before 240 us) or EOD (when passive at a byte boundary). These boundaries lie inside the Table 5 receive limits except that a long symbol is taken up to 169.8 us (J1850: 163). At EOD it checks the CRC; for its own frames it waits 20 us more and sends the normalization bit (64 us) and its address byte on the 8 us grid.

Host interface

Transmitter (hart 0): host bytes n, then n bytes (header first, at most 11). Answer: 0 sent; 1 and the IFR byte; 2 and the byte it lost arbitration in (1 = the first); 3 no IFR within EOF.

Receiver (hart 1): for each frame, n (bytes with the CRC), the bytes, a status (bit 0 CRC right, bit 1 IFR sent). The two harts share the host FIFO, so in a loopback their reports may interleave.

Data memory Use
0x00 receiver address (0 = 10h)
0x01 frames received
0x02 frames with a wrong CRC
0x03 IFRs sent
0x04 frames dropped for a symbol out of range or over 12 bytes
0x05 arbitrations lost (transmitter)

Tests

test/test_j1850.py, run from a private directory:

T=<repo>/test; R=$T/sim_build/<name>; mkdir -p $R; cd $R
PYTHONPATH=$T make -B -f $T/Makefile PWD=$T SIM_BUILD=$R/build COCOTB_TEST_MODULES=test_j1850

The models are written from the sources above, not from the firmware: the CRC with the Table 1 values, a symbol builder, a wired-OR bus that records every level and the chip's drives, a frame decoder with the Table 5 receive windows (SOF, bits, EOD, normalization bit, IFR, EOF), a model transmitter with any symbol times, and a model IFR responder. Only pins, host bytes and data memory addresses come from the firmware header.

Limits

  • IFR types 1 and 2 only (one byte, no CRC); type 3 and an IFR that loses arbitration are not handled; the receiver does not decode another node's IFR.
  • The transmitter does not retry after losing arbitration; no break (BRK) is sent, and a received break only drops the frame.
  • A long symbol is taken up to 169.8 us (J1850: 163 us).
  • Only the consolidated 3-byte header is used to decide the IFR; the one-byte header forms are passed through.
  • Simulation only: no board, no gate-level run.
