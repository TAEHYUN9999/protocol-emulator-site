firmware/profibus.pe One hart: a minimal PROFIBUS DP slave at the logic pins of an RS-485 transceiver: 8E1 characters, SD1 and SD2 telegrams with FCS and end delimiter, the 33-bit idle before a request, the answer after min TSDR, FDL status, Slave_Diag, Set_Prm (ident check, min TSDR, master address), Chk_Cfg (one configuration byte), Data_Exchange with outputs to the data memory and inputs from the host, the frame count bit (a repeated request answered again without applying it). 388 of 512

This protocol was not part of the design when the RTL was written. It uses only existing instructions (shin, shin.lsb, shout, shout.lsb, high/low, waitp.to, tsetr/twait/tgeth/tgetl, the CRC unit as a parity counter, the host FIFO, the data memory and the frame buffer); the RTL is unchanged. Checked in simulation only, not on a board.

IEC 61158 and EN 50170 are sold and were not read. Everything below is taken from two public secondary sources that agree: Wikipedia, "PROFIBUS", and the open-source DP master profirust (source files named in the table). Where only profirust gives a value it says so.

Not implemented: SD3 and SD4 telegrams, token passing (the slave is passive), Global_Control (SYNC/FREEZE), the watchdog, extended diagnostics, configurations of more than one byte, DPV1, baud rate detection (the bit time is set in the data memory), the physical layer (RS-485 levels, termination).

Timing

The receiver samples each bit in its middle (half a bit time after the start bit's fall, then a bit time apart) and checks the parity with the CRC unit (polynomial 80h, a one-bit parity). A telegram is taken only after 22 idle bit times (two characters; a master leaves 33), so the slave falls back in step after any garbage. After a request the slave waits half a bit (the rest of the last stop bit) and then min TSDR bit times; it sets DE one bit time before the first start bit and clears it at the end of the last stop bit. Bit time 133 ticks (5.32 us, 187.97 kbit/s, +0.25 %) by default; 1302 ticks for 19.2 kbit/s.

Host interface

Input bytes come as FIFO frames of NIN bytes and replace the inputs at the next idle; outputs stay in the data memory.

Address Use
0x00 station address (0: 5)
0x01, 0x02 ident number (0: 0F42h)
0x03, 0x04 bit time in ticks (0: 133)
0x05 state: 0 wait for parameters, 1 wait for the configuration, 2 data exchange
0x06, 0x07 min TSDR in bit times, master address (255 none)
0x09 diagnosis status 1
0x0A, 0x0B input and output bytes (0 to 8)
0x0C the configuration byte Chk_Cfg must carry
0x0D, 0x0E, 0x0F counts: data exchanges, telegrams dropped, repeated requests
0x10..0x17, 0x18..0x1F inputs, outputs

Limits

  • Secondary sources only (the IEC and EN texts were not read).
  • One configuration byte, at most 8 input and 8 output bytes, no Global_Control, no watchdog, no SD3/SD4.
  • The slave never sends unless asked; it does not check the master address after Set_Prm.
  • Simulation only: no board, no gate-level run.
