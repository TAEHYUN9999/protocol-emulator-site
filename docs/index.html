Design

Architecture, the instruction set, and the blocks around the cores.

  • Architecture The blocks of src/project.v with their instance names (the figure of the README, docs/fig/src/gen_readme_figs.py).
  • ISA additions of branch int6: edges on every clock, waits on patterns and events Four small additions to the core (src/pe_core.v), all on instruction bits that the assembler has always written as 0.
  • Shift unit (SU) src/pe_su.v is a general shift unit: the firmware describes how a bit looks on the pins (clock phase, lanes, bit order, a waveform table, a stuffing rule, a sample ...
  • int5: SRAM data memory, 1024-word program, two cores Branch int5 grows the chip in the order of its design study (the plan of 2026-11-12, kept outside the repository): each step changes the meaning of something first and ...
  • Delay lines of P0 to P3 Branch int5d, part D1 of the plan of int5 (int5.md).
  • Fractional tick generator (R7) and twait.f An FPGA's clock manager (MMCM) makes a clock of any frequency with a fractional divider.
  • Debug unit: breakpoints, single steps and injected instructions (branch int6) src/pe_dbg.v lets the host stop a hart at a program address, run one instruction of a hart at a time, and run an instruction of its own on any hart, through the host ...
  • SRAM self test (MBIST) src/pe_mbist.v lets the chip test its own SRAM macros: it runs March C- or March SS on one macro through the macro's BIST port and keeps the first failing address, the ...
  • Capture (on-chip logic analyzer) The chip records what happens on the eight protocol pins P0 to P7 (uio[7:0]) without any firmware: the host configures and arms it over the host SPI link, and reads ...
  • Witness harts (on-chip protocol checkers) One hart drives a protocol, or an outside device does, and the other hart reads the same pins and checks them.
  • Clock duty and reset release Two assumptions about the clock and the reset pin that the RTL makes and the other pages did not state.
  • Margin scan: the chip maps a device's timing window by itself (first version) No RTL change.
  • Same pins, two roles Each hart drives the protocol pins P0 to P7 through its own output and enable registers, and a pin is the wired AND of the two harts' drives.
  • pegen: firmware from a table of levels tools/pegen.py turns a short JSON table into a transmit firmware for one-line protocols whose bits are fixed patterns of levels on a slot grid: pulse-width codes ...
  • Static deadline check The chip reports a missed period at run time: a twait that arrives after its period has run out sets the hart's sticky late flag (architecture.md).
  • Reference model and differential test tools/peiss/ is an instruction set simulator (ISS) of the core, written from docs/architecture.md and the encodings of tools/peasm.py.
  • Host reads of the shared SRAM without a steal: design, not built Status: a design for review (branch int5b, 2026-11-13).
  • What is new A protocol emulator usually imitates a part: it answers like an EEPROM, a sensor or a debug target.
