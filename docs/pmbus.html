File Role Words
firmware/pmbus.pe A PMBus device with two outputs on the SMBus layer of smbus_target.pe (PEC, 25 to 35 ms timeout): PAGE, OPERATION, CLEAR_FAULTS, VOUT_MODE, STATUS_BYTE, STATUS_WORD, STATUS_CML, READ_VOUT (ULINEAR16), READ_IOUT and READ_TEMPERATURE_1 (LINEAR11, normalised by the firmware), and the communication faults of the specification. 310 of 512

This protocol was not part of the design when the RTL was written. It uses only existing instructions; the RTL is unchanged. Checked in simulation only, not on a board.

Section numbers are those of the PMBus Power System Management Protocol Specification Part II - Command Language, Revision 1.3.1 (13 March 2015), downloaded from pmbus.org. The SMBus layer (Part I refers to SMBus) is that of smbus_target.pe and docs/smbus.md (SMBus 3.2).

Spec item Section Firmware
LINEAR11: 5-bit two's complement exponent N in bits 15..11, 11-bit two's complement mantissa Y, X = Y x 2^N 7.3, Figure 4 rlin: from the host's fixed point value and exponent, shift right (N + 1) until Y fits -1024..1023
VOUT_MODE: bits 6..5 = 00b ULINEAR16, bits 4..0 the exponent; a device with a fixed mode rejects a write as invalid data 8.3, Table 2, 8.4.1.1 14h (exponent -12); a write NACKed, CML bit 6
PAGE 00h..1Fh, FFh = all outputs 11.10 pages 0 and 1; FFh writes OPERATION to both, reads give page 0; another value is invalid data
OPERATION bit 7: output on 12.1.1 per page; the STATUS OFF bit follows it
STATUS_WORD: low byte = STATUS_BYTE, bit 6 OFF, bit 1 CML 17.1, 17.2 Table 16 high byte 0
STATUS_CML: bit 7 unsupported command, 6 invalid data, 5 PEC failed 17.7 Table 21 a write clears the bits set in its data (10.2.4)
CLEAR_FAULTS clears the fault bits 15.1, 10.2.3 STATUS_CML = 0
A wrong PEC: NACK it, do not act, CML and bit 5 10.8.1 wpec
Too many bytes: NACK, invalid data (bit 6) 10.8.5 wmany
Unsupported command: NACK it and the data, bit 7 10.9.2 wlen returns FEh
Command codes and transfer types Appendix I 00h, 01h, 03h, 20h, 78h, 79h, 7Eh, 8Bh, 8Ch, 8Dh

Not implemented: the other commands of Appendix I (limits, fault responses, VOUT_COMMAND, MFR_*), SMBALERT#, the CONTROL pin, PHASE, block reads, Direct and IEEE half formats, reading too many bytes as a fault (the device sends FFh but does not set CML bit 1).

Pins

P6 = SCL, P7 = SDA, open drain, as smbus_target.pe.

Host interface

Address Use
0x00 own 7-bit address (0: 40h)
0x01 timeout: SCL low longer than this x 65535 ticks (0: 10, 26.2 ms)
0x07 PAGE
0x08 STATUS_CML
0x09, 0x0A OPERATION of page 0 and 1
0x0C, 0x0E VOUT of page 0 and 1, unsigned 16 bit in 2^-12 V (= the READ_VOUT data with VOUT_MODE 14h)
0x10, 0x12 IOUT of page 0 and 1, signed 16 bit in 1/256 A
0x14 temperature, signed 16 bit in 1/16 degC

16-bit values are low byte first. The host sets them while the harts are stopped (DATA_W), standing in for the device's measurements.

test/test_pmbus.py (cocotb). A PMBus host built on the SMBus 3.2 controller model of test_smbus.py (PEC, Table 2 timing), with the PMBus decoding (LINEAR11, ULINEAR16 with VOUT_MODE, STATUS bits) written from Part II. Controls

Each change was made in a copy of pmbus.pe and run with PMBUS_FW pointing at it. All fail, each at the check it aims at:

Change Test Caught by
LINEAR11 exponent not counted up on a shift test_pmbus_cmds READ_IOUT decodes to 3.13 A (N -8) instead of 100.3 A
PAGE ignored by reads (always page 0) test_pmbus_cmds READ_VOUT after PAGE 1 gives 1.2 V instead of 3.3 V
A wrong PEC accepted test_pmbus_faults the OPERATION write with a wrong PEC is ACKed and carried out
An unsupported command ACKed test_pmbus_faults 55h is ACKed (and no CML bit 7)

Limits

  • Two pages, three measured values per page set by the host, no conversion of real measurements.
  • LINEAR11 is normalised only downward (right shifts); a small value keeps the host's exponent and fewer significant bits than possible.
  • The SMBus layer runs at 100 kHz in the tests (Table 2 checked); the PEC is optional on every transfer, as in SMBus.
  • Simulation only: no board, no gate-level run.
