Claude Code is Anthropic's coding agent. The author's git configuration sets the commit author name to Claude Code, so the name alone does not say who made a commit; the Co-Authored-By: and Claude-Session: lines are what record AI involvement. None of these counts says how much of a commit the author wrote or changed by hand.

Commands:

git rev-list --count HEAD
git log --format='%an' HEAD | sort | uniq -c
git log --format=%B HEAD | grep -o 'Co-Authored-By: Claude[^<]*' | sort | uniq -c
git log --format=%B HEAD | grep -c 'Claude-Session:'
git log --author='Claude Code' --format=%s HEAD | grep -cP '[\x{AC00}-\x{D7A3}]'   # subjects in Korean

Code that is not the author's or the AI's, for completeness: the Tiny Tapeout template (.github/, test/tb.v, parts of info.yaml and test/Makefile), the SRAM macro views in macro/ (IHP Open PDK), and src/pdn_cfg.tcl (from the Loom project, Apache-2.0, credited in its header).
